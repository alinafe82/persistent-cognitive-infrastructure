# AdSense publisher verification

Publisher: `pub-9595222068473508` (ad-code client: `ca-pub-9595222068473508`).

The public metadata and `/ads.txt` authorize this publisher and allow site ownership verification without loading advertising JavaScript. Deploy the production build, confirm `/ads.txt` returns the Google record as plain text, then add the actual public domain in AdSense → Sites and verify using Ads.txt or Meta tag.

Verification does not mean Google has approved the site or that it is earning. Resolve any content or policy findings before requesting review. Before enabling ad serving, publish the required consent messages in AdSense Privacy & messaging, update the site's privacy disclosure, and obtain site approval. Use a Google-certified CMP for visitors in regions where Google requires one.

Only substantial public publisher content is eligible for ad placement. Keep case workspaces, financial records, calculators with personal inputs, account pages, admin pages, checkout, downloads, and confirmation screens free of ad scripts. Do not enable site-wide Auto ads on an application that shares a document with private workflows.
